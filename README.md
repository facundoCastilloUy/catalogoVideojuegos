# Mood Atlas

Mood Atlas es un catálogo interactivo de videojuegos pensado para descubrir qué jugar según el estado de ánimo, el tiempo disponible y el tipo de experiencia que se busca.

El proyecto fue desarrollado como parte de la materia Programación de la carrera de Diseño Digital, trabajando con HTML, CSS y JavaScript Vanilla.

## Sitio online

https://mood-atlas.netlify.app/

## Sobre el proyecto

La idea inicial fue construir un catálogo que no ordenara los videojuegos únicamente por género o popularidad, sino también por criterios más personales: cómo se siente el usuario, cuánto tiempo tiene para jugar y qué tipo de experiencia quiere encontrar.

A partir de esa base, el sitio evolucionó hacia una identidad propia bajo el nombre **Mood Atlas**, combinando la idea de atlas, exploración y curaduría de videojuegos.

## Funcionalidades

- Catálogo de videojuegos.
- Filtros por estado de ánimo, duración y género.
- Buscador por nombre.
- Sistema de favoritos.
- Sistema de votos.
- Página de detalle para cada videojuego.
- Formulario de sugerencias.
- Diseño responsive.

## Tecnologías utilizadas

- HTML
- CSS
- JavaScript Vanilla
- LocalStorage
- Netlify

## Identidad visual

La identidad de Mood Atlas toma como punto de partida la idea de un mapa digital.  
El sistema visual combina estética pixel, paleta oscura, acentos en azul, violeta y cyan, y una lógica de exploración asociada al descubrimiento de videojuegos.
